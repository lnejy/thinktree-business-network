# ThinkTree Business Network

프로젝트 루트에서 PowerShell로 `./start.ps1`을 실행하고 [ThinkTree](http://localhost:8443/)에 접속합니다. 서버가 이미 켜져 있으면 실행 중인 주소가 표시됩니다.

## ThinkTree 팀 계정

첫 실행 때 원재연, 고범창, 양승민, 이해인, 윤혜정의 계정을 만듭니다. 각 계정의 아이디와 초기 비밀번호, 추가 가입에 쓰는 초대 코드는 로컬 `backend/runtime/team-access.json`에 저장됩니다. 팀원에게는 각자의 계정 정보만 전달하세요. 새 팀원은 로그인 화면의 **회원가입**에서 초대 코드로 가입할 수 있습니다.

기존 명함은 다섯 팀원에게 순서대로 배정합니다. 대기함에는 본인이 받은 검토 대기 명함이 표시되며, 관리자는 팀 전체 대기함을 확인할 수 있습니다. 확정된 명함은 팀 네트워크에서 열 수 있습니다. **명함 받은 사람**에 함께 받은 팀원을 추가하면 해당 팀원의 **My Cards**와 **Business Network**에도 연결됩니다.

## 명함 등록 시나리오

1. **Dashboard → Add Card**에서 명함을 촬영하거나 사진을 여러 장 선택합니다. 사진을 올리면 자동으로 읽기를 시작합니다.
2. 같은 화면에서 원본 사진과 자동 입력된 정보를 비교합니다. 비어 있는 회사명과 이름을 입력하고, 나머지 정보는 필요할 때 **전체 항목 보기**에서 수정합니다. 기존 명함과의 관계가 애매하면 근거를 보고 연결 여부를 선택합니다.
3. **이 명함 저장**으로 현재 명함을 확정합니다. 여러 장을 확인했다면 **저장 가능한 명함 N장 저장**을 누릅니다. 읽기에 실패하면 같은 화면에서 **다시 시도**하거나 사진을 새로 올립니다.
4. 나중에 이어서 확인하려면 **Incoming Cards → 검토**로 들어갑니다. **임시 저장**을 누르면 수신 명함으로 돌아옵니다. **명함 삭제**는 확인 후 진행합니다. 검토 화면의 **명함 확정 저장**을 누르면 명함 상세가 열립니다.
5. 저장한 명함은 **My Cards**에서 확인합니다. 명함 상세에서 사진을 확대하고, 이전 소속과 연결 근거를 확인합니다. **Organization**과 **Business Network**에는 확정한 명함이 반영됩니다.

회사 조직도에서 **조회 기준일**을 선택하면 당시 명함 기록으로 확인할 수 있는 소속을 표시합니다. 기준일을 입력하지 않은 명함은 등록일을 추정 기준으로 사용합니다. 잘못 연결된 경우 명함 상세의 **정보 수정 → 소속 날짜 및 연결 설정**에서 별도로 등록할 수 있습니다.

기존에 불러온 명함은 **Incoming Cards**에서 사진과 함께 확인할 수 있습니다. OCR 평가 자료와 실행 방법은 [개발용 평가 결과](backend/EVALUATION_RESULTS.md)를 참고하세요.
