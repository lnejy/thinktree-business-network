# ThinkTree Business Network

[명함 원본 및 OCR 테스트 결과 목록](backend/EVALUATION_RESULTS.md)에서 명함 20개의 원본 이미지, 인식 텍스트, JSON, 인식 영역 이미지를 확인할 수 있습니다.

[전체 OCR 테스트 HTML 보고서](backend/OCR_테스트_결과.html)는 내려받아 브라우저로 열어주세요. 기존 테스트 결과를 포함했으며 새 OCR이나 외부 AI 호출은 수행하지 않았습니다.

## UI에서 원본과 OCR 결과 확인

프로젝트 루트에서 PowerShell로 `.\start.ps1`을 실행하고 http://localhost:8443 에 접속합니다. 로그인 후 **Incoming Cards → 기존 OCR 테스트 명함**을 선택하면 제공된 명함 20장이 사진과 함께 표시됩니다.

이미 서버가 실행 중이면 시작 스크립트가 기존 서버를 감지하고 접속 주소를 표시합니다. 반복 실행해도 서버를 중복 실행하지 않습니다. 다른 프로그램이 포트를 사용 중일 때는 해당 프로그램을 종료하지 않고 안내합니다.

명함 사진이나 목록 행을 클릭하면 원본 사진, OCR 원문, 모델별 신뢰도, 내용 포함률·문자 정확도·줄 일치율, 인식 영역 이미지를 확인할 수 있습니다. 사진을 다시 클릭하면 확대되며 원본 크기로 새 창에서 열 수도 있습니다. 상단 **전체 OCR 보고서**에서 기존 HTML 보고서를 열 수 있습니다.

기존 자료는 서버 시작 시 `backend/cards`와 `backend/out`에서 한 번 불러옵니다. **기존 OCR 자료 불러오기** 버튼은 새로 추가한 자료를 불러오며 기존 수정·확정 내역을 덮어쓰거나 중복 등록하지 않습니다. 반려한 자료도 자동으로 재등록하지 않습니다. 등록 데이터는 `backend/runtime`에 저장됩니다.

정답지 원문은 로컬에 유지합니다. 정답지가 없는 환경에서도 기존 테스트 지표를 볼 수 있도록 `backend/evaluation_metrics.json`에 저장된 OCR 결과와 연결된 요약 지표를 포함했습니다. 새 OCR·외부 AI 호출은 수행하지 않습니다.

검증: `frontend`에서 `pnpm typecheck`, `pnpm test`, `pnpm build`; UI/API 실행 후 `pnpm test:evaluation`. API 테스트는 `backend`에서 `.\.venv\Scripts\python.exe -m unittest test_api`로 실행합니다.

## 여러 명함 등록과 소속 이력

**Add Card**에서 사진을 여러 장 선택하거나 끌어놓으면 자동으로 인식합니다. 촬영 방향과 대비를 보정하고, 글줄을 기준으로 기울기를 줄입니다. 같은 화면에서 확인이 필요한 항목을 수정하고 개별 또는 일괄 저장합니다. **전체 항목 보기**로 자동 입력값도 수정할 수 있습니다.

확인한 기준일을 입력하면 그 날짜를 사용합니다. 빈 경우에는 등록일을 추정 기준일로 표시합니다. 최신 소속은 기준일, 확인 날짜 여부, 등록 시각 순으로 결정합니다. 명함 상세와 **Business Network**에서 이전 소속, 변경된 필드, 연결 근거를 확인할 수 있습니다. **Companies → Organization Chart → 조회 기준일**에서는 그 날짜까지 남은 명함 기록으로 조직도를 구성합니다. 근무 기간이 겹치는 사람도 명함 기록의 기준일 사이 구간으로 추정합니다.

같은 이름이나 영문명에 개인 이메일 또는 휴대전화가 일치하면 같은 인물로 연결할 수 있습니다. 회사는 정규화한 이름과 업무 도메인, 주소, 우편번호, 사업소 대표번호를 비교합니다. 근거가 일부만 일치하거나 강한 후보가 여러 개이면 저장 전 연결 대상을 선택합니다. 저장한 명함의 **Edit → 연결 분리 · 별도 등록**으로 인물 또는 회사 연결을 다시 나눌 수 있습니다.

## 인식과 연결 평가

`backend`에서 아래 명령을 실행하면 합성 명함 11종의 OCR 문자 오류율과 항목별 결과를 `runtime/registration_evaluation.json`에 기록합니다. 한국어·영어·일본어·혼합 언어, 가로·세로, 저해상도, 기울기, 잘림, 반사, 그림자, 작은 글씨, 복잡한 배경을 포함합니다. `--live`를 생략하면 정답 텍스트를 사용해 항목 추출만 평가합니다.

```powershell
.\.venv\Scripts\python.exe evaluate_registration.py --live
```

이번 합성 평가에서는 정답 텍스트에서 항목 66개 중 66개, 실제 OCR 텍스트에서 58개를 맞혔습니다. 실제 OCR 기준 회사명 10/11, 이름 8/11, 부서 9/11, 직책 10/11, 이메일 10/11, 휴대전화 11/11이었습니다. 기울기 사례의 문자 오류율은 기울기 보정 전 68.7%에서 보정 후 0%로 내려갔습니다. 잘린 사례에서는 6개 중 1개만 일치했습니다. `frontend`의 `pnpm test`는 이직, 동명이인, 공용 주소, 회사명 별칭과 같은 연결 사례 10건을 별도로 평가합니다.
